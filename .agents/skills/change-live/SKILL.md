---
name: change-live
description: Change a live tool after approval, starting with rollback.
---

This command will handle rollback, a release on request, secrets, access and leavers, adoption gaps, restore tests, moves and retirement after exporting data. With no detail it will ask which change is needed, listing rollback first. It will state what it will do before asking for approval of each change; `/check-live` is the read-only check. It is not built yet. Report that to the person and stop without running tools or changing files or infrastructure.
