---
name: setup-hosting
description: Set up or adopt a place to run tools. Checking is /check-live.
---

This command will help choose a host, check its fit, show a plan summary for approval and set up a place to run tools, including backups, access and alerts. It will ask whether merges go live automatically and record the place. For existing hosting it will first read and record what it finds and list gaps without changing anything; checking an existing place belongs to `/check-live`. It is not built yet. Report that to the person and stop without running tools or changing files or infrastructure.
