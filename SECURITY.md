# Reporting a security problem

AI Host Kit is beta and experimental. It will guide a coding agent working
with hosting accounts and access, so an unsafe instruction may affect more
than the kit's files. The current commands are stubs.

Use [GitHub's private vulnerability reporting](https://github.com/gwpicard/ai-host-kit/security/advisories/new).
You can also open the Security tab and choose "Report a vulnerability". Do not
open a public issue for a security problem.

Include the kit version, installation route, expected behaviour and the
smallest steps that reproduce the problem. Remove secrets, personal data and
private project details. You do not need to prove exploitation or propose a fix.

The maintainer will assess whether the report affects released files or only
the source. There is no response-time commitment. Problems in a hosting
provider or coding agent belong with that vendor; unsafe kit instructions
belong here.
